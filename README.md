# Comics page

A historical HTML/CSS layout exercise for a comics detail page. It contains a static page, a cover image and stylesheet; navigation and cover controls are mock interface elements.

Open [Comics page.html](Comics%20page.html) in a browser, or run:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000/Comics%20page.html`. Bootstrap is loaded from a CDN and requires an internet connection.

This repository is retained as an early learning example. No reuse license has been granted, and rights to the comic artwork remain with their respective holders.
